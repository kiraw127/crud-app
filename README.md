# RentAuto

Локальный сервис аренды автомобилей: ASP.NET Core API, Angular и PostgreSQL.

## Учётная запись администратора

- Email: `admin@rentauto.local`
- Пароль: `Admin123!`

Администратор управляет автомобилями и просматривает/отменяет аренды. Клиенты создают учётную запись через форму регистрации и могут только бронировать доступные автомобили.

Пароли хранятся в виде защищённых хешей. После входа API выдаёт JWT-токен сроком на 12 часов. Регистрация всегда создаёт пользователя с ролью клиента; роль администратора через интерфейс получить нельзя.

## Запуск

Требуются Docker Desktop, .NET SDK 10 и Node.js 20+.

```bash
docker compose up -d
cd backend/CarRental.Api
dotnet restore
dotnet run
```

Во втором терминале:

```bash
cd frontend
npm install
npm start
```

Откройте `http://localhost:4200`. API Swagger: `http://localhost:5148/swagger`.

Если приложение уже было запущено до добавления авторизации, ничего удалять не требуется: таблица пользователей и администратор создаются автоматически при старте API.

## Остановка базы

```bash
docker compose down
```

## Стандарты проекта

- REST-маршруты используют существительные во множественном числе: `api/cars`, `api/rentals`.
- Действия над текущим пользователем находятся по маршруту `api/rentals/me`.
- HTTP-методы соответствуют операции: `GET` — чтение, `POST` — создание, `PUT` — обновление, `DELETE` — удаление.
- Методы C# имеют явные имена и суффикс `Async` для асинхронных операций.
- Сообщения коммитов следуют Conventional Commits, например: `feat(auth): add JWT login` или `fix(rentals): link booking to user`.

Проверка и автоматическое форматирование фронтенда:

```bash
cd frontend
npm run format:check
npm run format
```

Форматирование C# выполняется из папки API:

```bash
dotnet format
```

## Архитектура

Фронтенд разделён по назначению:

- `core` — модели, API-сервисы, guards и HTTP interceptor;
- `shared` — переиспользуемые визуальные компоненты;
- `features` — отдельные сценарии клиента, администратора и авторизации;
- `layout` — общий каркас и навигация;
- `app.component.ts` — только корневой `router-outlet`.

Бэкенд разделён на HTTP-контроллеры, API-контракты, сервисы приложения, EF-модели,
маппинг и инфраструктуру. Контроллеры не содержат бизнес-логику и не принимают
EF-сущности в качестве входных контрактов.
